# Monopoly‑Go‑Bot

A Python bot for playing **Monopoly Go!** on idle, ideal for automating simple actions or gameplay pauses.

---

## Features

- Idle gameplay automation

---

## Tech Stack

- **Language**: Python
- **Script File**: `monopolygobot.py`

---

## Project Structure

```
.
├── Buttons               # Images for bot to detect
├── monopolygobot.py      # Main bot script
├── .gitignore
└── README.md             
```

## Getting Started

### Prerequisites

- Python 3.x  

### ▶️ Running Locally

```bash
git clone https://github.com/alihanbays/Monopoly-Go-Bot.git
cd Monopoly-Go-Bot

# Run the bot
python monopolygobot.py
```
